# EducationFrontend

Фронтенд для информационной системы поддержки ДО (дистанционного обучения).

Работает в связке с бэкендом: [EducationApi](https://github.com/TimofeyVlasov/EducationApi) (ASP.NET Core + PostgreSQL, REST API, JWT-авторизация).

Стек — на основе учебного курса по React (TypeScript, React, React Router, Axios, Redux Toolkit).

Проект в разработке.
